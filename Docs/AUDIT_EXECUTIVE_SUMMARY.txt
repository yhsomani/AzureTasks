───────────────────────────────────────────────────────────────────────────────
1. WHAT IS THIS APPLICATION?
───────────────────────────────────────────────────────────────────────────────

A production-grade TypeScript/Node.js automation system that:
  • Automatically creates daily task copies in Azure DevOps
  • Independently manages tasks for multiple team members
  • Prevents duplicate tasks via person-aware date checking
  • Copies relationships while protecting data integrity
  • Provides web dashboards for management & monitoring
  • Runs on schedule (daily at 09:30 AM IST on weekdays)

BUSINESS VALUE: Eliminates manual task creation, prevents errors, ensures
consistent team workflows, provides audit trail for compliance.
